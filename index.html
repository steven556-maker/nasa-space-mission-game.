    Learning referencesAll NOVA credits, mass units, power units, and fuel units are simplified game values, not NASA hardware specifications.
    How to read the resource model

    Budget is a game cost cap. Mass includes spacecraft components and the selected route hardware, and must fit both mission and launcher limits. Power compares daily supply with instrument and operations demand. Fuel includes launch, route, and mission operation reserves. Data compares generated science data with the estimated communications return window. Mission time combines transit and operations days.

    NASA’s science mission design guide covers launch, space, ground, and user segments. Mission Viz is a reference for visual communication; this game’s route math remains simplified.
